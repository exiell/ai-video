# AniGuide · AI 动漫视频创作向导

免注册的纯网页工具。云端模型按 Key 直连，本机模型通过 vLLM-Omni 接入。

它交付一份能直接开拍的前期方案：分镜表、角色与场景设定卡、多平台提示词、穿帮检查单，以及分镜三帧与 5 秒预览视频。拿到之后，你可以去即梦、可灵、Seedance 这些平台生成视频，也可以直接用本机模型出图、改图、出预览视频。



---

# 功能

主导航收拢为 **5 个清晰创作阶段**，跟着顶部制片通栏从左往右走，就是完整的制作顺序（原有 `/characters`、`/scenes`、`/checks`、`/prompts`、`/export` 路由均保留兼容）：

| 阶段 | 给你什么 |
|---|---|
| **作品主页** | 未打开项目时突出「创建新项目」与「导入项目」（支持导出的 `.zip` 压缩包或 `项目数据.json`，导入后自动落盘本机），并提供轻量化示例入口；打开项目后呈现三区制片总控台：四步进度与唯一行动卡、镜头预览与可点击时长节奏条、连贯性健康度三联卡 |
| **故事** | 3 步聚焦立项（定故事 → 画风与规格 → 启动制作）+ 右侧实时立项预览卡；支持自己写或 AI 起草，视觉化点选画幅比例、目标时长、平台与画风预设 |
| **设定集（角色 + 场景）** | 双 Tab 工作台，统一管理全片防穿帮锚点：角色三层设定（身份 / 变体 / 连续性锁）与全身多视图/头部特写，场景固定元素/主光/主色调与空场景参考板，均支持图像编辑 |
| **分镜与质检** | 吸顶全彩时间轴 + 内置穿帮质检与自动修复抽屉；展开单镜采用**左文右图双栏**——左栏按「① 起点 → ② 动作 → ③ 终点」三步脚本与防穿帮锚点填写，右栏按序生成三帧（首帧、动作关键帧、尾帧）与 5 秒本地预览视频 |
| **交付中心（提示词 + 打包与备份）** | 双 Tab 整合多平台英文正文/中文对照提示词（即梦、可灵、Seedance 等）与 `.zip` 打包下载、本机备份导入 |

每个镜头出三张图：首帧定构图、动作关键帧取动作顶点、尾帧接下一镜。接了本机改图模型后，任意一张已有图都可以做「图像编辑」：选参考图、写清要改什么，直接生成新版本。

**AI 副导演**常驻右下角悬浮抽屉，跨页保留对话状态。说大白话就行：把结局改成主角牺牲、第 3 镜太平了、加一个四十来岁的反派、删掉多余的第 5 镜。它给出可执行的字段级 diff 修改、新建或删除提议，你确认后才生效，且支持撤销。

**工具与外观**：顶栏右侧收拢为图标化的「帮助与术语（43 条分镜术语）」「设置（8 家厂商 Key 与自定义本地接入）」「关于」及本机保存状态指示灯；内置 **5 套外观**。

# 核心亮点

## 一、清晰简洁的新手引导

- **3 步立项 + 实时预览**：故事页一次只聚焦一件事，右侧常驻立项预览卡，实时呈现画幅比例框、目标时长、预计镜数与画风标签。
- **作品主页只给唯一的「下一步」**：按项目实时状态算出当前最急的一项（写故事 → 补设定 → 拆镜头 → 修穿帮必改项 → 调时长 → 出参考图 → 出分镜三帧 → 交付导出），去除重复文字待办噪音。
- **分镜左文右图双栏**：展开单镜时，左侧用「① 起点 / ② 动作 / ③ 终点」极短填法提示消除新手困惑，进阶视听参数默认折叠；右侧专注三帧按序生成与 5 秒预览视频。

## 二、一致性审查与防穿帮体系

跨镜穿帮是 AI 动漫最劝退的问题：角色变脸、衣服变色、场景换样。两个手段压住它。

### 手段一：五道一致性防线

| 层 | 做法 | 管什么 |
|---|---|---|
| **连续性锁** | 你登记的英文短语原样写进相关每一帧 | 服装、道具、场地固定物 |
| **角色形象图** | 全身多视图与头部特写各出一张，按景别挑一张当参考图 | 脸和体型说不清，只能靠图 |
| **本镜首帧** | 后两帧拿它当构图锚点 | 这一镜怎么取景，形象图锁不住 |
| **上一镜尾帧** | 仅在转场标「承接」时用作跨镜锚点 | 两镜的空间、光线、主体位置接不接得住 |
| **场景参考板** | 空镜与广角用它固定空间 | 同一个地方不像两个地方 |

出图顺序也按这条链走：先出角色形象图与场景参考板，再按镜头顺序，每镜首帧、关键帧、尾帧连着出。

不同模型能收的参考图张数不同：本地 FLUX3 最多 10 张，部分云端模型和改图模型只有 3 张。两个角色同框的承接镜要 4 张参考图，超过上限时按景别决定先丢谁：全景先丢形象图，中景以里先丢场景板。丢掉的会写进生成结果，不静默。

### 手段二：26 条规则 + 分镜内置质检抽屉

查的是文本约束，也就是该一致的地方有没有写下来，在花钱出图之前提前暴露大部分穿帮：

| 规则 | 它在说什么 |
|---|---|
| 相邻镜同景别 | 连着两个中景，观众觉得没剪 |
| 画面描述里的代词 | 提示词是给模型看的文字，它不知道「他」是谁，两人同框一定错位 |
| 抽象情绪词 | 「难过」指导不了画面，模型只能随便挑一种 |
| 单镜位移过大 | 几秒内跨越大段距离，中间那段最难补得自然 |
| 场景光线冲突 | 场景卡定的是傍晚暖光，这一镜写成正午顶光 |
| 场景空间结构缺失 | 门开在哪、什么在左没写下来，每镜都在重新猜 |

每条说清三件事：哪里错、为什么错、怎么改。分镜页右上角可直接唤出**穿帮质检抽屉**，点击任意问题立即定位并展开对应镜头，修完后红点实时消失；也可切换 `/checks` 查看全屏清单。



### 自动修复：只提议，不直接改

只提议能机械确定的修改：补锁、补字段、统一时长。需要审美判断的一律不碰。每条带修改前后对照，逐条勾选确认后才落盘，且支持撤销。

# 本地模型（可选）

不想用云端、或者想省调用费，可以把模型跑在自己机器上。AniGuide 通过「设置 → 自定义接入」接入，本地模型不需要 Key。

| 用途 | 参考模型 | 接口 | 显存 |
|---|---|---|---|
| 文字与分镜 | Qwen3.6-27B 等 | OpenAI 兼容 `/v1` | 1 张 24GB 卡 |
| 生图 | FLUX.3 Image Klein | vLLM-Omni chat 多图 `/v1/chat/completions` | 1 张 24GB 卡 |
| 图像编辑 | Qwen-Image-Edit-2511 | 同上 | 3 张 24GB 卡（CPU offload） |
| 预览视频 | SkyReels-V3-R2V-14B | OpenAI Videos `/v1/videos` | 1 张 24GB 卡（低显存模式） |

- 部署脚本不在本仓库内，需要按模型官方说明自己启动服务；地址形如 `http://127.0.0.1:8098/v1`，端口以实际启动为准。
- 浏览器访问本机服务时，要在开发环境里放行或转发对应端口；设置里的「测试连接」会区分服务没起、跨域被拦、模型未加载。
- 本地模型生成的图片和视频都存在浏览器 IndexedDB 里；删除项目会一起清理。
- 实测速度：单卡 24GB 跑视频预览约 11–12.5 分钟一条（5 秒），3 卡跑改图约 40–170 秒一张。具体以你的显卡和模型版本为准。

# 如何开始

## 第 0 步：把项目拿到手

```bash
git clone https://github.com/exiell/ai-video.git aniguide
cd aniguide
```

仓库名是 `ai-video`，项目叫 AniGuide，这里用 `aniguide` 作本地目录名，不加也行。没装 git 就在仓库页面点 Code → Download ZIP。

## 第 1 步：一键启动

Windows 双击 `start.cmd`。macOS / Linux：

```bash
chmod +x start.sh    # 只需一次
./start.sh
```

第一次约 1 分钟装依赖，之后很快，装完自动开浏览器。

&lt;details&gt;
&lt;summary&gt;不想用一键脚本？点开看手动步骤&lt;/summary&gt;

需要 Node.js 20+ 跑开发服务器（没有就去 https://nodejs.org/zh-cn 装 LTS 版）。跑测试另需 Node.js 22.22+（`jsdom@30` 的要求）：`bash scripts/test.sh` 会优先用项目内 `.tools/node-v22`，没有的话用系统 Node；版本不够会直接报错，不会静默跳过测试。

```bash
node -v            # 确认 >= 20
corepack enable    # 如果 pnpm 不是命令
pnpm install
pnpm dev           # → http://localhost:5173/
```

&lt;/details&gt;

脚本替你处理几件容易卡住的事：没装 Node 就给出下载地址；版本太低就说清需要 20 或更高；没有 pnpm 就自动装；依赖装过就跳过；端口被占用就提示可能已经开着一个；项目在同步盘里就提醒可能报 EBUSY。

## 上手顺序

1. 在作品主页直接点「创建新项目」开始，或点「导入项目」恢复之前导出的 `.zip` 压缩包 / `项目数据.json`（想先看成品结构，也可以点下方「打开示例项目」）。
2. 打开 `/cors-check.html`（设置页也有入口），确认网络能直连厂商。跨域是浏览器的策略，命令行能通不代表浏览器能通。
3. 设置里按厂商填 Key，点「测试连接」。它会当场说清是跨域被拦、密钥无效、余额不足，还是模型名不对。
4. 想用本机模型：设置 → 自定义接入，按「本地模型」一节新建文字/图片/视频配置，测试连接通过后，再到默认模型里选用。
5. 按顶栏 5 阶段推进：故事 → 设定集 → 分镜与质检 → 交付中心。
6. 需要改稿时，点右下角悬浮「AI」胶囊打开 AI 副导演。

想换外观：点顶栏右侧设置图标 → 外观，5 套里任选，选择会记住。

## 常用命令

```bash
./start.sh        # 一键启动（Windows 双击 start.cmd）
pnpm dev          # 开发服务器
pnpm test:local   # 跑测试（优先用项目内 Node 22.22+；pnpm test 会先检查版本，不满足直接报错）
pnpm build        # 生产构建 → dist/
pnpm typecheck    # 只做类型检查
pnpm check:copy   # 界面文案与字号检查

# 一次性诊断脚本（需要联网）
node scripts/provider-probe.mjs   # 核验各厂商能否从浏览器直连
```

# 其他

## 它明确不做

一键成片、完整视频生成与剪辑、配音字幕音乐、自动发布、账号系统、云端存储、训练模型。

分镜可以生成 5 秒本地预览视频，但只做单镜预览，不做拼接成片。

## 8 个厂商开箱可用

已实测确认浏览器可直连：DeepSeek、阿里云百炼（通义千问）、智谱 GLM、月之暗面 Kimi、MiniMax、阶跃星辰、硅基流动、百度千帆。也可以按「本地模型」一节接本机模型。

Key 是厂商级的，同一家的对话与出图共用一个，只填一次。每家都写明直连证据，没实测过的如实标「未核实」。

出图请求体按字段映射构造。各家字段名不同，加一家只改数据不改代码。

## 你的数据与备份

- 所有项目数据、图片与预览视频都存在浏览器的 IndexedDB 里。不配代理时，请求只在你的浏览器和厂商之间发生，中间没有服务器。
- API Key 默认存在这台电脑上，下次打开不用重填。电脑是共用的就勾「不保存到本机」，Key 只存在当前会话，关掉浏览器即失效。
- 阿里云返回的图片链接 24 小时后失效。AniGuide 在拿到图当下就下载留存成 base64，你看到的每一张图都真正属于你。
- **完整导入与重启持久化**：在「作品主页」或「交付中心」均可以直接导入本工具导出的 `.zip` 压缩包（自动读取 `项目数据.json` 并恢复 `图包★` 中的图片）或单独的 `项目数据.json`。导入后会立即写入本机 IndexedDB，刷新或重启工具后依然保存在「本机已有项目」中可正常打开与编辑。

## 技术栈

Vite 6、React 19、TypeScript strict、Zustand、Dexie、Zod、fflate。纯静态产物，可以直接丢到任意静态托管。

没有 UI 组件库，样式手写，通过 `data-theme` 驱动 CSS 变量与主题专属布局（`prism` 与 `pop` 采用顶部制片导航与悬浮 AI 抽屉，`studio` / `night` / `blueprint` 保留经典三栏布局）。

图标来自 [Tabler Icons](https://github.com/tabler/tabler-icons)（MIT），厂商标识来自 [Simple Icons](https://github.com/simple-icons/simple-icons)（CC0-1.0），蓝图外观的网格底纹参考 [css3patterns](https://github.com/LeaVerou/css3patterns)（MIT）。三处都是按许可引入的原始 SVG，不引入图标库运行时。

所有模型调用必须经过唯一入口 `ModelGateway`，业务代码不允许直接 fetch 厂商接口。默认直连厂商；在设置里填了代理才会走代理，代理能看到请求内容和 API Key，只填自己信任的地址。

目录分工见 [CONTRIBUTING.md](https://www.google.com/search?q=./CONTRIBUTING.md)。
